# 워크플로우와 API를 분석 데이터 소스로 사용하기

워크플로우의 성공한 Output과 DAC 저장 쿼리의 실행 결과는 같은 데이터 소스 계약을 사용합니다. 특정 EDS/Defect 컬럼을 전제로 하지 않으며, 결과의 컬럼과 타입으로 분석과 엔진 비교를 구성합니다.

## 사용 흐름

1. **Analysis** 또는 **Engine VS**에서 워크플로우 / DAC API / 저장된 소스를 선택합니다.
2. 워크플로우는 게시 버전과 inputs를 지정해 새로 실행하거나 성공한 과거 실행을 선택합니다. API는 query_id를 선택하고 기본 바디나 실행 이력의 바디를 수정합니다.
3. **데이터 불러오기**를 누르면 결과를 PostgreSQL의 변경 불가능한 스냅샷으로 저장합니다. 워크플로우 ID·버전·실행 ID·입력 또는 API query_id·버전·바디·이력 ID를 함께 보관합니다.
4. Analysis에서 날짜 컬럼을 기본 X로, 숫자 컬럼을 Y로 선택합니다. Category는 독립 차트, Legend는 시리즈입니다. 라벨·포인트 크기·이미지/HTML 내보내기를 사용할 수 있습니다.
5. Engine VS에서는 같은 스냅샷에 대해 DuckDB, Spark, DataFusion을 실행합니다. Join/Merge는 입력 B를 추가합니다. 두 입력은 API와 워크플로우를 자유롭게 섞을 수 있습니다.

API Console의 **분석 소스로 / Engine VS 소스로**는 현재 편집한 바디를 전달합니다. 워크플로우 성공 실행의 동일한 버튼은 해당 실행의 Output을 캡처합니다. 워크플로우 목록의 분석 링크는 소스 선택 화면을 엽니다.

**Saved Views는 분석 설정을 명시적으로 저장하는 기능**입니다. 분석 실행만으로 자동 생성되지 않습니다. 소스 ID와 차트 옵션을 저장하므로 다시 열어도 원본 API나 워크플로우를 재실행하지 않습니다. 최신 데이터는 새로 불러오세요. 원본 워크플로우가 삭제되어도 이미 캡처한 소스와 저장 분석은 유지됩니다.

## 비교 의미

- 집계: 선택한 숫자 컬럼의 COUNT, 유효 값 COUNT, SUM, AVG. 그룹 컬럼은 선택 사항입니다.
- 필터: 입력 A에 적용합니다. 비교 연산과 NULL/NOT NULL을 지원합니다.
- Join: 복합 키 및 inner/left/full. B 컬럼은 `right_` 접두사를 붙입니다.
- Merge: 컬럼 이름을 맞춘 UNION ALL. 없는 컬럼은 NULL, 중복 행은 보존합니다. 충돌하는 타입은 거부합니다.
- 세 엔진에 동일한 스키마와 값을 가진 Parquet 입력을 제공하고 입력 체크섬을 표시합니다.
- 결과 순서를 무시하고 중복을 보존한 **전체 결과** 체크섬을 비교합니다. 숫자는 소수 6자리 HALF_EVEN 반올림으로 정규화하므로 비트 단위 동일성을 뜻하지 않습니다. 화면 미리보기는 20행입니다.
- 준비 시간은 Parquet 작성, 엔진 시간은 세션/테이블 준비·조회·결과 수집입니다. 합계와 큐 대기를 구분합니다. 원본 API/워크플로우 실행과 HTTP 전송은 엔진 시간에 포함하지 않습니다.
- 같은 서버에서 순차 실행하며 실행 ID에 따라 순서가 바뀝니다. Spark는 동일 물리 서버의 워커 2개입니다. 단일 측정이므로 일반적인 엔진 성능 순위로 해석하지 마세요.
- 실행은 PostgreSQL에 저장됩니다. 화면을 닫아도 계속되며 기록을 다시 열 수 있습니다. 서버 재시작 때 실행 중이던 항목은 interrupted로 표시합니다. 실패를 다른 엔진으로 대체하지 않습니다.

## 범위와 제한

작은 단위의 소스는 최대 **10,000행 / 8MB**입니다. DAC 쿼리 자체의 제한(현재 최대 1,000행)은 그대로 적용됩니다. 비교 출력도 10,000행을 넘으면 오류를 반환하며 조인 조건이나 필터를 좁혀야 합니다. 숫자 입력은 DECIMAL(38,10) 범위이며 초과 정밀도를 조용히 잘라내지 않습니다. 문자열 필터의 역슬래시와 NUL은 엔진별 차이를 피하기 위해 거부합니다.

기존 1천~100만 행 스트림/합성 데이터 기능은 별도 경로에 남아 있습니다. 새로운 워크플로우 소스 기능이 100만 행을 처리한다고 표시하지 않습니다. 현재 공유 작업 공간이며 소스와 비교 이력에 사용자별 권한/자동 보존 기간은 없습니다.

## 주요 API

| API | 용도 |
|---|---|
| `POST /api/sources` | `{kind:"api",queryId,body}` 또는 `{kind:"workflow",runId}`로 소스 캡처 |
| `GET /api/sources` | 최근 100개 소스 목록 |
| `GET /api/sources/{id}` | 스키마·출처·건수·체크섬 |
| `GET /api/sources/{id}/rows?offset=0&limit=100` | 결과 페이지 |
| `POST /api/source-comparisons` | 스냅샷 ID와 연산 조건으로 비동기 비교 생성, 202 `{id}` |
| `GET /api/source-comparisons/{id}` | 엔진별 진행 상태·시간·체크섬·미리보기 |
| `GET /api/source-comparisons` | 최근 30개 비교 기록 |

실행 검증은 `scripts/sources-integration.py`, 브라우저 검증은 `scripts/sources-browser.cjs`를 사용합니다. 브라우저 검증은 앞선 통합 검증이 만든 `artifacts/sources-integration.json`을 사용합니다.
