# Engine VS와 Drill 콘솔

- 통합 비교 화면: http://192.168.50.186:8082/#engines
- Drill 자체 웹 콘솔: http://192.168.50.186:8047

Engine VS에서 완료된 원본 스냅샷을 선택하고 **3개 엔진 비교 실행**을 누릅니다.
DuckDB, Spark, DataFusion에 같은 원본 ID와 join/merge/filter 조건을 전달합니다.
데이터가 없으면 Data streams에서 한 번 수집해 완료된 데이터셋을 준비합니다.

세 카드는 나란히 표시하되 같은 호스트의 CPU 경합을 줄이도록 순차 실행합니다.
화면 내 재실행 시 순서를 회전합니다. 준비·엔진 실행·전송/조정·총 시간을 별도로 표시하고
총 시간이 가장 짧은 결과를 표시합니다. 최초 Kafka 수집과 작업 큐 대기는 측정에서 제외됩니다.
Spark 세션의 첫 기동과 캐시, 엔진별 입력 변환 및 Parquet 전송 비용이 결과에 영향을 줍니다.
현재 Spark 워커는 물리 서버 한 대의 컨테이너 두 개입니다.

결과 행 수 일치만 확인하며 전체 값의 동일성 검증으로 표시하지 않습니다.
실패는 각 카드에 표시되고 나머지 비교는 계속됩니다. 대기 중단/화면 이동은 서버 작업을 취소하지 않습니다.
결과 데이터셋과 실행 시간은 Data streams에 저장되며 각 카드에서 분석 화면을 열 수 있습니다.

Drill은 엔진 선택 목록에서 분리했습니다. 8047은 Drill이 제공하는 실제 Query/Storage/Profiles UI입니다.
`waferscope.root` workspace는 공유 `/engine-data` 디렉터리를 가리킵니다.
`SHOW FILES IN waferscope.root`로 파일을 탐색할 수 있습니다.
`./scripts/deploy-engines.sh`는 서비스 기동 후 이 workspace를 등록합니다.
DataFusion은 사용자 선택에 따라 별도 UI 대신 VS 비교 대상으로 포함했습니다.

## 비교 복원과 내보내기

최근 비교의 원본 ID, 엔진별 작업 ID, 결과, 실행 순서를 브라우저 sessionStorage에 보관합니다.
같은 탭에서 화면을 이동하거나 새로고침해도 복원됩니다. 탭을 닫은 후 다른 탭/다른 기기에서의
비교 묶음 복원은 지원하지 않습니다. 서버의 개별 결과 데이터셋은 Data streams에 남습니다.
중단하거나 돌아온 후에는 **결과 상태 갱신**으로 서버 결과를 다시 확인할 수 있습니다.
아직 제출하지 않은 엔진은 미실행, 접수한 작업은 대기 중단으로 구분합니다.
완료된 엔진의 원본/결과 ID와 준비·엔진·총 시간은 **비교 결과 CSV**로 내려받습니다.
