JSON의 UUID는 검증 당시 로컬 데이터 식별자이며 다른 설치에서 그대로 사용할 수 없습니다. `artifacts/`의 실행 기록을 문서용으로 복사했습니다. 숫자 결과는 소수 6자리로 정규화하고 행 순서를 무시하되 중복을 유지해 전체 결과를 비교했습니다. 입력은 각 엔진에 동일 스키마·값으로 제공했습니다.

현재 새 소스의 범위는 최대 1만 행/8MB이며 이 검증을 100만 행 소스 지원이나 멀티 머신 성능 검증으로 확대 해석하지 않습니다.
