# 통합 점검과 보강 · 2026-11-13

## 수정한 사항

- Engine VS 최근 비교를 같은 브라우저 탭에서 복원: 새로고침과 화면 이동 대응.
- 실행 순서도 저장하고 다음 비교 순서를 회전하여 순서 설명의 일관성 유지.
- 서버 작업 상태 다시 조회: 화면을 떠났거나 대기를 중단한 작업의 완료 결과 확인.
- 중단 후 미실행 엔진과 이미 접수된 작업을 구분.
- 완료된 결과만 차트 분석으로 연결.
- 비교 결과 CSV: 엔진, 원본/결과 ID, 시작 시각, 상태, 행 수, 준비/실행/총 시간.

## 점검 결과

- Kubernetes Pod와 Spark/DataFusion/Drill 컨테이너 실행 상태 확인.
- 디스크 사용률 5%, 가용 공간 약 1.7TB 확인.
- .NET 186개 테스트 통과: Portal 48, DAC 21, Chart 61, Data.Transform 56.
- 프런트엔드 28개 테스트 통과.
- 실제 Portal 통합 23개, 차트 옵션 API 6개 검사 통과.
- TypeScript/Vite production build 및 Kubernetes 재배포 수행.

## 다음 우선순위

현재 결과는 같은 물리 호스트의 비교입니다. 반복 실행 분포(p50/p95), 정확한 결과 값 비교,
CPU/메모리·동시 부하 측정이 다음 성능 개선의 근거가 됩니다.
공개 운영을 하려면 인증/사용자 권한, DB 마이그레이션과 백업·복구 검증이 우선입니다.
최근 비교 묶음의 다중 기기 공유는 별도 서버 저장 기능이 필요합니다.

기존 기능: Oracle 데이터 API, Kafka 수집/변환, 3엔진 VS, 차트/이미지/CSV,
PostgreSQL 분석 저장·이력, Drill 자체 UI를 유지합니다.

최종 브라우저 검증도 통과했습니다: 실제 3엔진 실행, 새로고침/메뉴 이동 후 결과 복원,
서버 결과 상태 갱신, 3엔진 CSV 다운로드, Drill 자체 UI, 모바일 너비.
